---
name: "review-evidence"
description: "Assess code changes against acceptance criteria and assemble reproducible review evidence."
---

Compare the exact changed artifact with the acceptance criteria and approved task boundary.
Inspect tests for observable behavior, failures and recovery cases.
Record verified check identities, artifact revisions and unresolved findings.
Use references/evidence-template.md when reporting evidence.
Treat CI, review and remote results as observations until the host completion gate verifies them.
